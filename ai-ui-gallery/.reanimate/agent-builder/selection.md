# agent-builder: selection

Candidates reviewed (one screenshot and one short capture each):
- Arc UI "Agent builder": loaded. Inline-named agent card with model picker, instructions, six tool toggles, knowledge files with upload progress, Configure/Test switch, test chat (thinking, tool chips, streamed answer), Publish bar with unsaved state. WINNER.
- beUI Pro "Agent Builder": loaded. Split workspace (configuration left, live test chat right) with typing indicator, Unsaved badge, Save agent. Good, but needs a very wide layout and the preview shows less lifecycle on its own.
- Arc UI "AI setup wizard": loaded. Three-step setup card (connect data with sync progress, behavior, test with cited answer). Polished and auto-playing, but narrower in scope and shows the pattern as onboarding rather than agent configuration.

Reason: judged on polish, completeness, motion and AI-pattern clarity only. Arc Agent builder covers the most states in one compact card (configure, upload, test run with tool use, publish state), and its test run reads clearly as an agent pattern. Runner-up: AI setup wizard.
