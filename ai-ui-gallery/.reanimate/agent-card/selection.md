# agent-card: selection

Each candidate: one screenshot + one short capture (1440x1000, 2.5 s, after 5 s settle). All six loaded; none failed.

- **assistant-ui Agent card**: static card (name, version, skills, endpoint, Connect); tabs Default / Connected / No skills / Long details. Clean but a single static tile, no run motion.
- **UIStacks Agent card**: polished tile with status pip, tool chips, three stats, rules and actions, inside a chat thread; status roll and number rolls on interaction. Good single-agent card.
- **UIStacks Agent roster**: team total at top, rows with role/model, live task line, spend, status pills, expandable last three steps. Tidy list, small motion.
- **beUI Pro Agent Team (Org chart)**: lead agent plus six sub-agents in a tree; connectors draw in per agent colour, cards go Queued -> Running (progress ring) -> Done on a scripted run, header running count and cost digits roll. Also has Run steps and Subagent tree variants.
- **Arc UI Agent gallery**: marketplace grid of agent templates with tabs, search and install flow. A catalogue, not a live team.
- **UIStacks Agent control frame**: browser-agent frame with status line, timer, Stop / Take over. Different concept (computer use).

**Winner: beUI Pro Agent Team, Org chart.** It is the most complete and best-moving view of an agent team: a whole run plays unattended with sequenced starts, parent-to-child connector draws, filling rings, rolling counters and a clear Done end state, and it reads at once as a multi-agent pattern. Runner-up: UIStacks Agent roster (clean, compact, expandable steps). The Run steps and Subagent tree variants on the same beUI page are variants of the same component, so only one clone was made.

Fidelity: motion-faithful (own palette, fonts, lucide icons, fictional agents and copy).
