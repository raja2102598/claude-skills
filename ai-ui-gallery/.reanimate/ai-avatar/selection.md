# ai-avatar selection

Candidates (one screenshot + one 3 s capture each, cand-arc/ and cand-lib/):
- **Arc UI "AI mascot"** (https://uiarc.dev/components/ai-mascot): loaded (needs ~6 s). A character with six states (idle, listening, thinking, writing, done, error), an auto-cycling tour, inline status line and state switcher. WINNER.
- **Libraries.dev "Bot avatars"** (https://libraries.dev/bots): loaded. Gallery of plush 3D canvas shapes (clover, flower, ghost, square) with look-around/hop/doze, plus a bot list and a thinking chat row. Polished art, but a showcase of looks with far less state and AI-pattern clarity.

Winner on quality alone: Arc mascot is more complete (full state machine, status text, error and done reactions), moves with clearer intent, and reads directly as an AI-status pattern. Fidelity is motion-faithful (own character "Pip", palette, copy).
