# ai-button: selection

Candidates reviewed (one screenshot and one short capture each; all three loaded):
- **Wensity "AI Button"** (https://ui.wensity.com/components/ai-button): six button variants (solid, gradient, ember, mesh, soft with shortcut, icon only). Click runs a full async action: sparkle, then stop square and a shimmering status label, then a second label, then a done check, then rest. Labels swap with a blur, and the width follows. **Winner.**
- **Arc UI "AI spark"** (https://uiarc.dev/components/ai-spark): a very polished animated spark mark with five states (idle, thinking, writing, done, error). It is a mark with a state switcher, not an action button. Runner-up.
- **Arc UI "AI command"** (https://uiarc.dev/components/ai-command): a Cmd+K palette with a streamed answer and sources. It is a different concept (palette), not a button.

Why Wensity: it is the most complete action-button flow (idle, running with stop, progress phases, done, reset), its motion is the most coordinated (blur swap, width follow, shimmer, sheen) and it reads at once as an AI action. The Arc spark's mark animation is richer but covers only the "spark" half of the concept.

Cloned: the gradient variant only, motion-faithful, own palette (teal), DM Sans, own sparkle SVG, lucide Check.
