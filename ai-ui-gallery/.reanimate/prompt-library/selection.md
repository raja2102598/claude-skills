# prompt-library: selection

Candidates reviewed (one screenshot each; Playwright "Target crashed" under memory pressure on several loads, each retried once with no video and then loaded):
- assistant-ui "Prompt library" (loaded, MIT not checked): small search box, three rows with variable counts, and a preview of the selected prompt. Clean but minimal, no editing or running.
- beUI Pro "Prompt Library" (loaded after one crash retry): dark card with search, category pills with counts, starred rows, and a fill-in-variables dialog. Polished, a list pattern only.
- UIStacks "Prompt library" (loaded after one retry): list with variable chips, usage counts and a composer to insert into. Pleasant but small.
- UIStacks "Prompt versions" (loaded): version history with eval scores, sparkline, diff of two versions and Restore. Strong for versions, nothing for editing or testing.
- Arc UI "Prompt studio" (loaded): one card with a system/user editor, variable chips, token counter, per-case variable fields, a simulated run that thinks and streams, plus version and model pickers.

Winner: Arc UI "Prompt studio". Chosen on quality alone: it is the most complete (edit, parameterise, run, version, switch model in one block), has the richest motion (run state swap, shimmer, streaming, auto-height output) and reads most clearly as an AI authoring pattern.
Runner-up: UIStacks "Prompt versions". No second clone, since versions are covered by the studio's version chip.
Fidelity: motion-faithful (own palette, Geist, lucide, fictional copy).
